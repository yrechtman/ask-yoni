ask-yoni

A public MCP server for semantic search over 99% Derisible, Yoni Rechtman's newsletter on startups and investing.

You aren't supposed to open this URL in a browser. It's a Model Context Protocol endpoint — add it to your AI client as a connector and ask questions about Yoni's writing through that.

The URL

https://yoni.fyi/mcp

Set it up

Claude.ai (web or desktop)

Settings → Connectors → Add custom connector. Paste the URL above. Name it whatever you like.

Claude Code
claude mcp add --transport http ask-yoni https://yoni.fyi/mcp
Cursor

Settings → MCP → Add new MCP server → choose HTTP transport, paste the URL.

What it does

It exposes four tools to your AI client:

  • search_99d — semantic search at the section level
  • get_post — fetch a full Substack issue by slug
  • get_section — fetch one section of an issue
  • list_recent — list the most recent issues

Once it's connected, try asking your AI things like "what does Yoni think about AI services companies?", "narrative warfare in VC", or "how should I think about seed pricing?"
